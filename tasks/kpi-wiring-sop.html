Standard Operating Procedure

Wiring the KPIs correctly

How to configure each KPI on the /kpis page so every number is provably correct, and you and Gage can trust them 100%. Follow it top to bottom.

1 · How it works (read this first)

Configuring a KPI is safe. Each KPI you wire overrides the old calculation just for that one metric. Anything you haven't wired keeps showing today's trusted number. So you can wire them one at a time, and nothing else on the page ever changes or breaks.

The preview is the truth. When you configure a KPI, a live preview shows the exact number and the records behind it before you save. The rule for 100% confidence is simple: only save once the preview matches the number already on the card.

You can't break it. A nonsensical configuration can't even be saved, and one KPI can never affect another. Worst case, you cancel and the card is untouched.

2 · The wiring process (repeat for each KPI)

  1. Open the KPIOn /kpis, hover the KPI and click the gear (⚙), or click Configure on an unwired one.
  2. Pick the IntegrationWhere the data lives: Stripe (money in), Meta (ad spend), Proposals, GHL, Internal (expenses), or Σ Combine.
  3. Pick the ScopeWhich set of records — e.g. "Money paid in", "Invoices", "Subscriptions", "Proposals".
  4. Set the MeasureWhat to do with them — "Add up the total" (of an amount) or "Count how many" — and, if adding up, which amount.
  5. Add Filters & the dateNarrow it (e.g. status = Paid) and choose "count it by which date", or "a running total as of now" for live balances.
  6. Match the preview, then SaveConfirm the preview number equals the card for the same month. If it matches → Save config. If not → adjust before saving.

4 · Two decisions to make with Gage

Decision 1 — Total MRR

Your current Total MRR card = subscriptions plus software costs. A clean Stripe configuration would be subscriptions only. Either wire it and rename the card to "Subscription MRR", or leave Total MRR on the existing calculation and wire Management MRR instead.

Decision 2 — # Management Clients

The configured version counts active subscriptions; the existing card counts distinct customers. These are identical unless one customer holds two or more subscriptions. Fine to wire today — just know the difference for the future.

5 · The one rule that guarantees confidence

✓ Preview must equal the card before you save

For every KPI you wire, set the period to the same month the card is showing, and confirm the live preview number matches the card. If it matches, you've proven the wiring is correct — save it. If it doesn't, adjust the recipe (usually the date field or a missing status filter) until it does. Never save a preview that doesn't match.
